# lernspiele.aufner.org
Landing page and release pipeline of [lernspiele.aufner.org](https://lernspiele.aufner.org/), the learning games of Prof. Aufner. The games are built from their own repositories (`release-manifest.json`); `npm run release` fetches, checks, builds and deploys them (see `docs/RELEASE.md`).
